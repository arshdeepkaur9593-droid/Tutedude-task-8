# Laundry Service Hamburger Menu

## About the Project
This project is an extension of the Laundry Service website. It adds a responsive hamburger menu for mobile devices using HTML and CSS.

## Features
- Responsive navigation bar
- Hamburger menu visible only on mobile screens
- Menu opens on button focus using the CSS `:focus` pseudo-class
- Menu positioned on the right side of the screen
- Clean and user-friendly layout
- Responsive hero section for different screen sizes

## Technologies Used
- HTML5
- CSS3
- Media Queries
- CSS Pseudo-classes

## How to Run
1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Resize the browser window to test the responsive layout and hamburger menu.
